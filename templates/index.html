    About the Project

    WineQuality is a student machine-learning project in Data Science. It shows how predictive analysis can turn laboratory measurements into an estimated quality score. A Random Forest classifier, trained on the WineQT dataset, reads 11 physicochemical properties and predicts the quality score.

    A prediction is an estimate from measurements alone, not a tasting.

    Algorithm
    Random Forest Classifier (300 trees)
    Dataset
    Wine Quality (WineQT)
    Inputs
    11 physicochemical properties
    Output
    Quality score on a 0–10 scale

    How it works

    1. CleanThe Id column is dropped, duplicate rows are removed and extreme values are capped.
    2. SplitThe data is divided 80% for training and 20% for testing.
    3. TrainA Random Forest of 300 decision trees learns from the training data.
    4. PredictYour 11 values go in and the trees vote on the quality score.
